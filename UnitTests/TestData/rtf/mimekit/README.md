# MimeKit synthetic test documents

These documents were written for MimeKit and are distributed under the same MIT license as
MimeKit itself. They cover features found only in upstream corpus files that were excluded because
they contain personal information or third-party copyrighted prose. They also cover a few edge cases
no upstream file exercised. All text in them is neutral filler.

The `.txt` and `.html` files are expected output generated by MimeKit.

| File | Exercises |
|---|---|
| `nested-tables.rtf` | Replaces RtfPipe's `Issue34.rtf`. Nested tables (`\intbl`, `\cell`/`\row`, `\nestcell`/`\nestrow`, `\*\nesttableprops` both inside and after the content group, `\nonesttables` fallback text), `\ansicpg1251` with `\fcharset204` Cyrillic, non-breaking space `\~`, `\qc`. |
| `skipped-destinations.rtf` | Destinations that must not render: `\*\themedata`, `\*\colorschememapping`, `\*\xmlnstbl`, `\*\datastore`, footnote separators (`\ftnsep`, `\ftnsepc`, `\aftnsep`, `\aftnsepc`), `\headerl`/`\headerr`/`\headerf`, `\footerl`/`\footerr`/`\footerf`, annotations (`\*\atnid`, `\*\atnauthor`, `\*\annotation`), unknown `\*` destinations. Also an `\object` whose `\*\objdata` is skipped while its `\result` renders, and 12 levels of group nesting. |
| `charsets-and-sections.rtf` | `\fcharset136` (Big5) with adjacent high-byte `\'hh` escapes, `\cpg10000`, a malformed `{*\rsidtbl` (missing backslash, so `*` is literal text), `\footnote`, `\super`, `\page`, `\sect`. |
